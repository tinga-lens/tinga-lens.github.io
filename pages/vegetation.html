Vegetation & Forest

Track vegetation condition and forest change across Ghana.

About this module

Vegetation condition compares how green each district is with the same month in other years. Cloud hides the ground in the rainy season, so some districts are not rated in some months.

Forest change shows tree cover lost since 2001. Tree cover loss is not the same as deforestation: it includes plantation harvests and counts cocoa, rubber and oil palm as tree cover. Read the methods.
