Observed and condition products

The rainfall, soil moisture, vegetation, fire detection and tree cover products come from published datasets that their producers have validated. Tinga Lens has not yet carried out its own systematic comparison against ground measurements in Ghana. Until it does, treat the maps as guides. Reports from the ground that agree or disagree with a map are welcome: see the About page.

How to cite

To cite Tinga Lens as a whole:

Adekilae, F. A. (2026). Tinga Lens: Environmental monitoring for Ghana. https://tingalens.org. Accessed [date].

To cite one map or figure, use the "Cite this map" text beside the map. It names the map, its period and version, the date you viewed it, and the original data source, for example:

Adekilae, F. A. (2026). Rainfall compared with normal: Jun to Aug 2026, against 1991–2020. Tinga Lens, product version 1.1. https://tingalens.org/pages/drought.html#drought. Accessed 3 October 2026. Source data: CHIRPS v3.0.

Please also credit the original data provider named on each map. The maps change as new data arrive, so always give the date you viewed them.

How the data are processed

Every Monday, programs in the public code repository download the newest data from each source, average it over each district, compare it with the record, and publish the results as small files that these pages read. The processing code is written for this project and uses only publicly available datasets.

Downloads are available as CSV from every map and district profile. Each file names its source, date and product version.
